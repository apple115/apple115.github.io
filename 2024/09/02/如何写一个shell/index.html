shell 的特征

  • 输入一行 输出一行
  • 可以一直输入 输出 输入 输出
  • 输入exit 或 ctrl-c 会退出
  • 输入命令 输出结果

shell 的组成

可以认为shell 是一无线循环中
遇到exit 和 ctrl-c 退出
需要读取数据和解析数据 执行数据

我们可以分为几个函数
1.无限运行shell的函数
2.读取一行用户输入的函数
3.解析输入的函数
4.执行输入的数据
