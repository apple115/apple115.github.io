将doom-modeline 换成 header-line

主要原因是在emacs doom-modeline有点卡，不过大概率是因为vc git 在windows太慢了,同时突然感觉 doom-modeline的大部分功能我好像也不太需要，我就将其去除，开始尝试更加简洁，我尝试smart-mode-line 和 mini-mode-line，发现会影响我使用的 consult，感觉也不太美观,最后我发现了 nove theme 他使用header-line 替代 modeline，我感觉这个非常不错,就用ai 帮我写了一个 header-line的东西

感觉是非常不错呢

自己定义了一个主题

最近看了alabaster关于写代码的主题讲解, 我在之前没有这个的时候，使用cursor 选择了这个主题，发现非常适合写go语言，同时这个哲学我也非常喜欢,if for 这种关键最没有必要高亮，本身就是代码的一部分 ,string bool 这种值才是重要的，还有定义的函数名这些都是非常重要的 ,不过他的字体好像是不使用字体变形，我是非常喜欢字体变形的,而且一些花式斜体会给代码带来一种美感, 所以我可能会将比如注释什么的使用字体作为区别，而不是高亮,而且我又非常喜欢gruvbox light 主题，所以我做了一个mini版，自己用, 欢迎大家尝试
